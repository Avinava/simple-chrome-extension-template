# Icons Placeholder

This directory should contain your extension icons in PNG format:

- `icon16.png` - 16x16 pixels (for extension icon)
- `icon32.png` - 32x32 pixels (for extension icon)  
- `icon48.png` - 48x48 pixels (for extension icon)
- `icon128.png` - 128x128 pixels (for Chrome Web Store)

You can create these icons using any image editor or online icon generator.

For now, you can use any PNG images with the correct dimensions, or create simple colored squares as placeholders.
