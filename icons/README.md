# Extension icons

This repository includes starter PNG icons in the sizes Chrome expects:

- `icon16.png` - 16x16 pixels (for extension icon)
- `icon32.png` - 32x32 pixels (for extension icon)  
- `icon48.png` - 48x48 pixels (for extension icon)
- `icon128.png` - 128x128 pixels (for Chrome Web Store)

Replace all four files together with your extension's branded artwork. Keep the
same filenames, or update the icon paths in `src/manifest.json`.
