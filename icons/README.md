# Extension icons

The starter includes PNG icons at the sizes Chrome uses:

| File | Purpose |
| --- | --- |
| `icon16.png` | Toolbar and compact UI |
| `icon32.png` | Extension management UI |
| `icon48.png` | Extension and notification UI |
| `icon128.png` | Store listing and large surfaces |

Replace the whole set with your product artwork before publishing. Preserve the
filenames or update every corresponding path in `src/manifest.json`.
