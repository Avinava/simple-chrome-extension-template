# Documentation

This directory holds the guides that explain how to extend the template.

- [Architecture](architecture.md) — module boundaries, data flow, and patterns.
- [Design system](design-system.md) — tokens, themes, and reusable UI primitives.
- [Extension development](extension-development.md) — productizing the starter,
  permissions, messaging, and release checks.

Repository policies and contribution entry points stay at the root so GitHub and
common tooling can discover them: [CONTRIBUTING](../CONTRIBUTING.md),
[SECURITY](../SECURITY.md), [CHANGELOG](../CHANGELOG.md), and
[AGENTS](../AGENTS.md).
